## ✨ What is this?

CaloriePet turns your fitness data into a pet-raising game.

It does three simple but fun things:

1. 📊 **Reads your health data** (via Apple HealthKit)
2. 🎮 **Converts it to XP** (Calories × 1 + Steps × 0.1)
3. 🐣 **Feeds a virtual pet** (10 families, 3 evolution stages)

The result? You'll actually want to walk more just to see your pet evolve 🚶‍♂️

## 🚀 Quick Start

### Requirements
- iOS 17+ / watchOS 10+
- Xcode 15+
- Apple Developer account (for physical device testing)

### Installation

```bash
# 1. Clone the repo
git clone https://github.com/Fermi-lin/CaloriePet.git

# 2. Open in Xcode
open CaloriePet/CaloriePet.xcodeproj
```

3. Select iPhone + Watch simulator
4. Press Cmd + R to run

## 🎨 Customize Your Pet (5-min Guide)

Want to use your own pet images? Super easy:

**Step 1: Prepare images**
- Naming: `familyname_lv1.png`, `familyname_lv2.png`, `familyname_lv3.png`
- Example: `flamepaw_lv1.png`, `flamepaw_lv2.png`, `flamepaw_lv3.png`

**Step 2: Add to project**
- Drag into Xcode's `Assets.xcassets`

**Step 3: Modify Pet.swift**
```swift
enum PetFamily: String, Codable, CaseIterable {
    case flamepaw = "flamepaw"   // Your new pet
    // ... other families
    
    var displayName: String {
        switch self {
        case .flamepaw: return "Flame Paw"
        // ...
        }
    }
    
    var element: String {
        switch self {
        case .flamepaw: return "🔥 Fire"
        // ...
        }
    }
}
```

Done! Rebuild and you'll see your pet.

## 🎮 Core Mechanics

### XP Formula
XP = Calories (kcal) × 1.0 + Steps × 0.1

### Evolution Stages
| Level | Name | XP Required |
|-------|------|-------------|
| Lv.1 | Juvenile | 0 → 10,000 |
| Lv.2 | Growth | 10,000 → 30,000 |
| Lv.3 | Ultimate | 30,000 (Max) |

### 10 Pet Families
🔥 Flame Paw (Fire) | 💧 Tide Drop (Water) | 🌱 Sprout (Grass) | ⚡ Zap Kit (Electric) | ❄️ Frosto (Ice)
🌪️ Breezling (Wind) | 🪨 Pebblem (Rock) | ☀️ Glimmerite (Light) | 🌙 Lunara (Dark) | 🍄 Funglow (Fairy)
